## 使用说明

1. 打开 [GitHub Pages 页面](https://renge3647-netizen.github.io/smart-sports-report-2026/)。
2. 页面按**公告日期倒序**排列，每日为一个分隔区块。
3. 表格字段包含：公告日期、项目名称、采购单位、公告类型、金额、地区、来源、备注、原文链接。
4. 红色加粗项目为重点关注；红色金额为百万级以上项目。
5. 点击每行右侧「查看原文 →」可跳转至官方公告页面。

## 更新机制

- **自动更新**：每日上午 9:00（北京时间）自动检索并刷新。
- **更新内容**：新增当日招标 / 中标公告、补录近期遗漏项目、更新追踪项目状态、同步统计数字。

  - `智慧体育招投标监测报告_YYYY-MM-DD.md`：当日监测日报（Markdown 格式）。
